# Qelvra v0.1.0-beta.1

A source-run local workspace for persistent AI agents, terminals, tasks and reviewed multi-agent goals. Codex handles real automated execution; deterministic fake agents let developers exercise the full flow without external AI usage.

Clone the source archive/repository, use Node 22 and follow [README](../../README.md). This beta has no desktop installer, hosted deployment or npm distribution.

Agents currently operate in isolated workspaces. Qelvra coordinates their tasks and results but does not yet automatically merge edits into one shared project repository.

Keep loopback binding: there is no authentication and a workspace cwd is not an OS sandbox. Review [security](../../SECURITY.md), [provider support](../providers.md), [limitations](../limitations.md) and [storage/backup guidance](../architecture.md). Stop the server and back up DATA_DIR before upgrading. Storage version 1 is preserved; uncertain interrupted work requires inspection and explicit retry/resume.

Publication is gated by [the release checklist](v0.1-beta-checklist.md), including the owner-selected license. Do not create the suggested `v0.1.0-beta.1` tag until every P0 is resolved and the recommendation is SHIP.
