## Findings discovered during verification

- P1: preserved deleted-agent workspaces retained live Chokidar watchers. The router now unwatches both owner and outbox, ignores unregistered owners, and observes recreation. A 12-owner regression exercises the same server dependency used in production.
- P1: exclusive mailbox publication changes inode ctime when its temporary hard link is removed. A long soak reproduced MAILBOX_READ_FAILED after 46 cycles. A deterministic read/unlink regression reproduced the exact error in 100 ms. The reader allows only the publication 2-to-1 link transition while still checking size, mtime, inode, bounded JSON and envelope identity. Full soak restarted after the fix; earlier partial runs are not counted as passes.
- Verification contention: running build, two browser suites and unlimited Vitest workers together caused three cleanup/lifecycle timeouts. Vitest concurrency is bounded to two workers; browser release gates run serially with zero retries. No global timeout or mismatch budget was raised.

Owner selected Apache-2.0 on October 6, 2026; canonical LICENSE and Qelvra NOTICE are added. The subsequent artwork P0 is resolved: seven unverified Stitch files are REPLACED with six original Qelvra SVGs, with provenance and hashes in asset-audit.md/json. A narrow owner-approved UI-honesty cleanup disables/restyles misleading controls while retaining real Goal, zoom and desk selection. The release guard fails closed on canonical-license, artwork or checklist failures. Other final statuses are in the release checklist.

- P2: fresh npm ci reports five high entries inherited from the single unpatched braces advisory in Tailwind 3 development tooling. Fixed repository glob patterns; no API/user-input route reaches brace patterns. Runtime Chokidar 4 has no braces; production dependency audit is zero. See SECURITY.md for primary advisory and remaining development-tooling risk. Major Tailwind migration deferred to preserve approved rendering.
