## Fresh-clone test diagnosis

One full clean-clone run failed the resumed-planning fixture before restart: its default one-second startup poll saw no execution yet. Planning discovers eligible providers; this fake-only integration suite unintentionally probed installed real CLIs. Eight isolated repeats passed, then a controlled 1,200 ms delay on non-fake discovery reproduced the exact failure. Restricting the suite registry to the fake definition made that same delayed probe pass without changing polling, test or one-second goal-deadline limits. All 20 orchestration integration cases pass after the change. Provider discovery retains its separate real detector/registry tests. Temporary instrumentation was confined to a disposable clone and removed; no application behavior was changed.
