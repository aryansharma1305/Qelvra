## Brand & Style

This design system embodies the ethos of precision engineering, autonomy, and sovereign telemetry. Built for technical founders, AI researchers, and systems architects, the visual narrative rejects cartoonish cyberpunk tropes and hyperbolic neon glow in favor of a surgical, disciplined instrument aesthetic reminiscent of high-end flight decks, mission control consoles, and elite developer tools.

The interface evokes hyper-focus, deterministic control, and absolute speed. It treats autonomous agents not as conversational novelties, but as high-throughput distributed workers. Surfaces are carved from cold obsidian, layered with structural hairline dividers, and illuminated only by purposeful state-driven telemetry: disciplined ultraviolet pulses for orchestration, electric cyan for active data pipelines, and cold mint for verified execution states.

## Colors

The palette is engineered around deep optical absorption and measured spectral accents.

### Tonal Foundations
- **Canvas Base (`#09090B`)**: Void-like obsidian ground for global canvas margins and viewport backdrop.
- **Surface Elevation 1 (`#111114`)**: Structured panel backing, secondary sidebars, and inactive deck regions.
- **Surface Elevation 2 (`#16161A`)**: Interactive cards, active nodes, elevated sheets, and popovers.
- **Surface Overlay (`#1F1F24`)**: Active hover states, interactive dropdown rows, and pressed states.

### Core Accents & Telemetry
- **Primary Violet (`#8B5CF6` / `#7C3AED`)**: Core system actions, orchestration pathways, multi-agent thread focus, and sovereign commands.
- **Secondary Cyan (`#06B6D4` / `#22D3EE`)**: Real-time agent streaming, telemetry loops, network socket pulses, and live API ingress.
- **Tertiary Mint (`#10B981`)**: Deterministic completion, healthy micro-services, node consensus, and verified execution tokens.
- **System Warning (`#F59E0B`)**: Agent rate limits, memory pressure, and fallback protocol engagement.
- **System Error (`#EF4444`)**: Subprocess failure, broken chains, and security boundary violations.

### Typography & Dividers
- **Text Primary (`#F8FAFC`)**: High-contrast, optical white for headings, critical IDs, and focal labels.
- **Text Secondary (`#94A3B8`)**: Cool graphite for balanced descriptions and active metric readouts.
- **Text Muted (`#64748B`)**: Low-emphasis metadata, timestamps, and column titles.
- **Hairline Border (`rgba(255, 255, 255, 0.08)`)**: Universal structural stroke.
- **Active Border (`rgba(139, 92, 246, 0.35)`)**: Focused command line and active agent node highlight.

## Typography

Typography prioritizes information density, scanning velocity, and unambiguous glyph differentiation.

- **Prose & Structural Hierarchy (`Geist`)**: Used across display titles, sectional headers, interaction controls, and descriptive body copy. Tight tracking (`-0.02em` to `-0.03em`) on larger sizes creates an authoritative, solid editorial cadence.
- **Telemetry & Identity Engine (`JetBrains Mono`)**: Strict allocation for log output, execution durations, memory utilization, agent UUIDs, raw JSON payloads, terminal shells, and metadata micro-badges. 

Always preserve uppercase transformation for `label-sm` when indicating agent statuses (`IDLE`, `PROCESSING`, `CONSENSUS_REACHED`).

## Layout & Spacing

The layout philosophy follows a responsive multi-pane fluid workspace optimized for persistent density.

- **Grid Architecture**: A modular multi-column dashboard with fixed utility sidebars (64px collapsed icon rail, 280px secondary resource tree) and a fluid center canvas supporting 12-column sub-grids with `gutter` (16px) or `gutter-lg` (24px) spacing.
- **Section Margins**: Canvas borders utilize `margin` (16px) on mobile viewports, scaling to `margin-md` (24px) on compact laptops, and `margin-lg` (32px) on ultrawide monitors.
- **Reflow Logic**:
  - **Desktop (≥ 1280px)**: 3-pane layout (Navigation Tree / Command Workspace / Live Telemetry Inspector).
  - **Tablet (768px – 1279px)**: Inspector collapses into a contextual slide-over drawer; workspace scales fluidly.
  - **Mobile (< 768px)**: Viewports stack strictly to single-column full-width tiles; navigation shifts to an elevated bottom command sheet; font sizes scale dynamically via mobile tokens.

## Elevation & Depth

Visual depth is conveyed through material layering, translucency, and precise hairline containment rather than diffuse physical drop-shadows.

1. **Substrate (Level 0)**: Canvas background (`#09090B`), solid and non-reflective.
2. **Structural Paneling (Level 1)**: `#111114` with a 1px uniform perimeter stroke of `rgba(255, 255, 255, 0.08)`. No cast shadows.
3. **Floating Decks & Modals (Level 2)**: Glassmorphic composition using `#16161A` at 85% opacity, paired with `backdrop-filter: blur(16px)` and an ambient, faint cast shadow: `0 8px 32px -4px rgba(0, 0, 0, 0.6)`.
4. **Active Luminescence & Ray Tracing**: Focused input rings and active agent nodes feature a directional gradient border (`linear-gradient(135deg, rgba(139, 92, 246, 0.4) 0%, rgba(6, 182, 212, 0.1) 100%)`) complemented by an inner hairline glow: `inset 0 1px 0 rgba(255, 255, 255, 0.1)`.
5. **Telemetry Aura**: Live metrics and running agents project a calibrated, restrained glow using `box-shadow: 0 0 12px rgba(6, 182, 212, 0.25)`. Never exceed 16px blur or 0.3 opacity to avoid muddying the dark field.

## Shapes

The design system maintains a structured, compact geometry with a unified base curvature (`roundedness: 1`).

- **Interactive Inputs & Action Buttons**: `rounded` (0.25rem / 4px) to retain an intentional, engineered look.
- **Cards, Panels, and Containers**: `rounded-lg` (0.5rem / 8px) for clean delineation of multi-agent feeds.
- **Command Palettes & Floating Modals**: `rounded-xl` (0.75rem / 12px) to subtly differentiate elevated overlays from the underlying grid.
- **Badges, Status Nodes, and Micro-indicators**: Pill-shaped (`rounded-full` / 9999px) strictly for circular status pings and compact telemetry tags.

## Components

### Buttons
- **Primary**: Solid background `#8B5CF6`, text `#F8FAFC`, hairline top highlight `inset 0 1px 0 rgba(255, 255, 255, 0.2)`. On hover: `#7C3AED` with an subtle outer glow `0 0 16px rgba(139, 92, 246, 0.35)`.
- **Secondary**: Surface `#16161A`, border 1px `rgba(255, 255, 255, 0.08)`, text `#94A3B8`. On hover: surface `#1F1F24`, text `#F8FAFC`, border `rgba(255, 255, 255, 0.16)`.
- **Ghost / Terminal Action**: Transparent base, text `#94A3B8`, padding `space-xs` `space-sm`. Hover: `#16161A`, text `#F8FAFC`.

### Badges & Telemetry Chips
- **Micro-Badges**: JetBrains Mono uppercase (`label-sm`). Height 20px, padding horizontal 6px.
- **Agent Status Indicator**: Embedded 6px circular dot.
  - Active: `#06B6D4` with an animated ping ring.
  - Success/Idle: `#10B981`.
  - Stalled: `#F59E0B`.
- **Background**: Translucent tint matching the status color at 10% opacity, border 1px at 20% opacity.

### Input Fields & Command Omnibar
- **Height**: 36px (standard inputs), 48px (Command Omnibar / Agent Prompt).
- **Background**: `#111114`, 1px border `rgba(255, 255, 255, 0.08)`. Typography `body-md` in `#F8FAFC` with placeholder `#64748B`.
- **Focus State**: Border color `#8B5CF6`, outer shadow ring `0 0 0 1px #8B5CF6`.

### Cards & Agent Modules
- **Container**: Surface `#111114`, border 1px `rgba(255, 255, 255, 0.08)`.
- **Header**: Divided by 1px bottom border `rgba(255, 255, 255, 0.06)`, housing agent name (`headline-sm`), runtime ID in monospace (`code-sm`), and action dropdown.
- **Interactive State**: Transition on border color to `rgba(255, 255, 255, 0.18)` and surface tint to `#16161A` over 150ms ease.

### Selection Controls (Checkbox & Radio)
- **Checkbox**: 14x14px box, `#16161A` fill, border 1px `rgba(255, 255, 255, 0.2)`. Checked: `#8B5CF6` fill with sharp optical-white checkmark icon.
- **Radio**: 14x14px circle matching checkbox styling with an internal 6px solid white dot when selected.

### Real-Time Terminal & Log Streams
- **Container**: Solid `#09090B`, inset border 1px `rgba(255, 255, 255, 0.06)`.
- **Log Stream Rows**: `code-sm`, alternating hover highlight `rgba(255, 255, 255, 0.02)`. Timestamp in `#64748B`, process scope in `#8B5CF6`, message body in `#94A3B8`.
